# 정리 및 검증 기록

- 실행 파일: 루트 `index.html`, `assets/css/style.css`, `assets/js/main.js`, `assets/js/kakao-map.js`.
- 미사용 지도 이미지와 외부 참조가 없어진 SVG 파일을 제외했습니다. 인라인 아이콘의 Lucide 라이선스는 보관했습니다.
- 이전 지도·로고·갤러리 스타일 90개 규칙과 덮어써진 중복 선언 111개를 정리했습니다.
- 유지한 CSS 선택자/속성 818개를 원본과 비교했습니다. 미디어 조건별 최종 값이 일치합니다.
- JavaScript 두 파일은 서식 정리 전후 실행 내용이 같습니다. 문법 검사도 통과했습니다.
- 이미지·파비콘 파일은 현재 사이트 파일과 해시가 일치합니다.
- 로컬 파일 경로, 내부 앵커, 고유 ID, 새 창 링크 속성을 검사했습니다.
- `.git`, `.openai`, OS 임시 파일, 작업 도구, 기존 배포 아카이브를 업로드 폴더에서 제외했습니다.
- 브라우저에서의 실제 화면 비교와 카카오맵 렌더링 재검증은 이 정리 작업에서 수행하지 않았습니다.
